Para publicar:
1. Sube todos los archivos a GitHub Pages, Netlify, Vercel u otro hosting estático.
2. Verifica que index.html sea la página inicial.
3. Comprueba los enlaces entre las tres páginas.
4. Copia la URL pública y entrégala en Classroom.

Las imágenes utilizadas son enlaces externos de Unsplash. Si el docente exige imágenes propias, sustitúyelas por fotografías propias y actualiza las rutas en styles.css.
